# Transaction Processing System
### Mini Project - 24UCS271 Lab

---

## Objective

This project is a simple bank account transaction processing system written in C. It uses a random-access binary file to store account records and allows the user to add, update, delete, search, list, and summarize account information.

---

## Files Included

| File Name | Description |
|---------|-------------|
| `trans.c` | Main C source code |
| `credit.dat` | Binary file used by the program to store account records |
| `clients.dat` | Backup/sample binary data file |
| `accounts.txt` | Formatted text report generated by the program |
| `README.md` | Project details and instructions |
| `MINI PROJECT Guidelines.pdf` | Given project guideline document |

---

## Features

1. Generate a formatted `accounts.txt` report.
2. Update an existing account balance.
3. Add a new account.
4. Delete an existing account.
5. List all account records on the screen.
6. Search for an account by account number.
7. Display account summary:
   - Total active accounts
   - Total balance
   - Average balance
   - Highest balance
   - Lowest balance
8. Initialize/reset the account file.
9. Validate account number input.
10. Handle invalid user input.

---

## How to Compile

Open the project folder in VS Code terminal and run:

```powershell
gcc trans.c -o trans.exe
```

For warning checks, use:

```powershell
gcc -Wall -Wextra -pedantic trans.c -o trans.exe
```

---

## How to Run

```powershell
.\trans.exe
```

---

## Menu Options
